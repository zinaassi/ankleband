WHY COMPRESSION IS LOWER THAN EXPECTED
================================================================================

Expected INT8 compression: 4× (FP32 → INT8)
Actual compression: 1.97× (38.31 KB → 19.41 KB)

Reason: Incomplete quantization due to unfused BatchNorm layers

What happened:
1. Conv1D and Linear layers: Successfully quantized to INT8 ✓
2. BatchNorm layers: NOT fused, remained in FP32 ✗
3. Result: Only ~50% of model weights quantized

What should have happened:
1. Fuse BatchNorm into Conv1D/Linear before quantization
2. Quantize fused layers to INT8
3. Expected result: ~2-3 KB total file size, ~19× compression from baseline

Why this happened:
- PyTorch's quantization API requires explicit BatchNorm fusion
- Our QAT script used prepare_qat() but didn't manually fuse layers first
- BatchNorm fusion is NOT automatic in PyTorch quantization

Can this be fixed?
- Yes, by modifying the QAT script to manually fuse BatchNorm before quantization
- Would require retraining all models (~2-3 hours)
- Current performance is already excellent, so fix is optional
